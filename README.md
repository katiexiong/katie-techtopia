# TechTopia — Katie Xiong

A responsive, interactive personal portfolio website based on Katie's hand-drawn design.

## Files
- `index.html` — webpage structure
- `style.css` — colors, layout, responsive design
- `script.js` — gallery, quiz, chatbot, geometry visualizer, particle simulation, timer, homework tracker
- `assets/techtopia-logo.svg` — TechTopia artistic logo with girl-coder icon
- `Katie_TechTopia_Original_Sketch.png` — original student sketch
- `TechTopia_GitHub_Publishing_Instructions.docx` — step-by-step GitHub Pages publishing guide

## Quick local preview
Double-click `index.html`, or drag it into Chrome/Edge/Safari/Firefox.

## Features
1. Filterable Photo Gallery: All / School / Travel / Hobbies
2. Interactive multiple-choice Knowledge Quiz
3. Offline demo Chat Bot
4. Circle Geometry Visualizer with radius, diameter, circumference, and area
5. Particle Simulation with Moon/Earth/Jupiter/Zero-G gravity
6. Focus Timer with Start/Stop, Reset, and Change Time
7. Homework Tracker stored in the browser using localStorage

## Customize
- Replace sample gallery cards in `script.js` with Katie's real photos later.
- Edit quiz questions in the `quiz` array in `script.js`.
- Edit chatbot responses in the `botReply()` function.
- Change colors in the `:root` section at the top of `style.css`.
